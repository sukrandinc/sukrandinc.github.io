# sukrandinc.github.io

Personal academic website of Sukran Dinc, served by GitHub Pages.

- `index.html`: all page content (bio, research, teaching)
- `assets/style.css`: design
- `files/`: CV, paper and slides (the CV link opens `files/resume_sukran.pdf`)
- `images/portrait.jpg`: photo

To update the CV, replace `files/resume_sukran.pdf` with the new PDF under the same name.
Folders such as `publications/` and `cv/` only redirect old links to the new page.
